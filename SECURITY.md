# Security policy

## Reporting a vulnerability

The selected reporting channel is GitHub Private Vulnerability Reporting. Repository publication and activation of that channel are pending; no live reporting endpoint is available yet.

Once enabled, use **Security -> Advisories -> Report a vulnerability** in this repository. If that option is unavailable, open an issue requesting a private reporting channel without including vulnerability details. See [GitHub's reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

Include the affected revision, impact, and minimal reproduction using synthetic or rights-cleared inputs. Do not post exploit details, credentials, personal data, or restricted media in public issues or pull requests.

## Supported versions

The project has no released versions. There is no fixed response or remediation deadline.
